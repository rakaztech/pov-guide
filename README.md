# دليل POV للكويت — ملف التسليم

## شنو هذا المشروع
صفحة ويب وحدة (index.html) فيها دليل أماكن الكويت لحساب @pov.kw: 9 أقسام و158 مكان.
الفكرة: ينزل فيديو بالإنستغرام/تيك توك، المتابع يكتب كلمة بالكومنت، ويوصله رابط الصفحة بالدايركت عن طريق ManyChat (مع التحقق من الفولو).

## الملفات
- `index.html` — الصفحة كاملة بملف واحد (التصميم، اللوقوات، الصورة كلها داخله). ما تحتاج أي ملف ثاني.

## شلون تعدّل المحتوى
كل البيانات داخل `index.html` في قسم مكتوب عليه «البيانات — عدّل هني بس»:
- `LAST_UPDATE` — تاريخ آخر تحديث (غيّره مع كل تعديل).
- `CATEGORIES` — الأقسام والأماكن. لإضافة مكان: أضف اسمه داخل `items`.
- لتمييز مكان جديد بشارة NEW: اكتبه هكذا `{n:"اسم المكان", isNew:true}`.
- `LOGOS_R` — لوقوات دائرية (من حسابات الأماكن)، و`LOGOS` — لوقوات من المواقع الرسمية. المفتاح هو اسم المكان بالضبط مثل ما هو في `items`، والقيمة صورة base64.
- المكان اللي ما له لوقو يطلع له مربع فيه أول حرفين من اسمه تلقائياً.
